INSIGHT CANDIDATES
==============================================================================

I-M: Auth-inversion as a distinct pattern from auth-on-default
     Auth-on-default = platform ships open, operator expected to add auth
     Auth-inversion = platform has NO mechanism to add auth; openness is the product
     Streamlit is the cleanest example in the corpus.

I-N: BARE null-coverage as research-class gap signal
     Zero MSF coverage across an entire category (< 0.55 all findings) reliably
     signals a research-class gap: the attack surface predates the module corpus.
     Confirmed now in Cat-33 (OSS guardrails) and Cat-Streamlit (ML webapps).

I-O: Static file handler as exfil primitive in ML webapp deployments
     ML webapp frameworks (Streamlit, Gradio pattern) often serve arbitrary files
     for model artifact delivery. The same handler that serves model weights can
     serve /proc/self/environ. Path traversal is a structural risk, not accidental.

==============================================================================
ANALYST NOTES
==============================================================================

Streamlit differs from all prior survey categories in one key dimension: the
auth gap is not a misconfiguration. Every other category (Ollama, MLflow,
vector DBs) ships with open defaults that operators are expected to override.
Streamlit provides no override path. The product has no auth module at all.

This creates a different remediation posture: the recommendation cannot be
"set AUTH_TOKEN" or "configure a reverse proxy as documented." There is no
documented auth path. The correct remediation is network isolation by design.

The CVE coverage (64% CVE-2024-42468, 96% CVE-2024-36473) makes this the
highest CVE-density population in the corpus to date.
